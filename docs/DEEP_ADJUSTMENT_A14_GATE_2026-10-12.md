# 16 位调整图层阶段验收

第一阶段冻结版本：`0.3.0-alpha.14`。完成后才开始普通画笔、涂抹、液化及重采样实现。阶段基准 `npm run check` 835/835，双语检查、类型检查与生产构建通过。实际 Electron 脚本 `scripts/smoke-deep-composite.ts` 的 11 项检查通过，报告 `artifacts/deep-composite-dev/acceptance.json`。

合成从原始 premultiplied RGBA16 开始，8 位图层按原版 premultiplied byte ×257 提升。8 类调色调整、24 种混合、不透明度、栅格蒙版（独立位置、密度、羽化）、pass-through 组和连续同父级剪贴堆栈在高位深运算。视口采样后才一次量化为屏幕 RGBA8；命中测试保留源显示图缓存。保存 `.comp` 的原始 PNG16 与合成无关，不被覆盖。

桌面覆盖 8 种调整的只读预览与提交结果相同、源字节保持、透明度与调整参数、Undo/Redo、模糊笔刷草稿在调整下方的真正高位深合成、保存重开与隐藏渲染服务缩略图。核心 45 项合成测试另覆盖混合方程、低 alpha、剪贴、组及蒙版。缓存和工作内存有上限；草稿 PNG 的 ancillary identity 区分会量化为相同显示像素的不同高位深源，并校验所属图层。

现阶段拒绝可见栅格效果、向量蒙版、未支持调整（例如调整层 Gaussian Blur）、非连续/跨父级剪贴依赖及超预算堆栈，提交前检查候选堆栈保持原子性。不会偷偷采用 8 位合成完成这些操作。原版非 Normal 调整混合本来走 8 位，此处实际 16 位混合属于精度改进，不能称全部像素与原版相同。Core Graphics 私有采样与 Photoshop 效果没有逐像素一致性证明；显示和渲染导出仍为 8 位，浮点 HDR 未实现。
