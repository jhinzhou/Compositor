# Photoshop 真实输出与项目效果：首轮像素测量

2026-10-12。参考来自主流程在本地 **Photoshop 27.11.0** 用 File > Scripts > Browse 执行 `scripts/native-reference/photoshop-reference.jsx` 得到的 `artifacts/photoshop-native/outputs/v3`。`native-results.tsv` 的 18 项 PASS 表示原生脚本操作及保存成功，**不表示与项目的效果验收通过**。本轮只测其中 12 个图像滤镜/恒等案例。

输入为 512×320 RGBA8 `analysis-grid.png`：SHA-256 `88fee62adb55cb448f0052b82abb289a975eab88d574c419c81d01ecf52f47e7`，含灰阶渐变、彩色块、半透明/透明区域。不是用户的“选品调研”图片，也不是外部照片。Photoshop 日志记录 untagged，PNG 未携带 ICC/sRGB/gAMA 等色彩声明；比较不额外转换色域。本项目使用 sRGB 工作语义，因此本轮是固定输入的数值对照，不能据此宣称完整 ICC/显示色彩管理一致。

## 复现与参考边界

运行 `npx tsx scripts/compare-photoshop-reference.ts`，或传入另一个原生输出目录。工具读取真实 Photoshop identity 作为该位深的操作输入，经过实际 `Editor → layer.filter → asset` 路径，再对 Photoshop 导出的无损 PNG 比较。JSON 记录参考/输入/项目输出 hash、实际参数、位深、尺寸、placement、代码 hash、分区指标与差异最大的坐标。

原始输入、8 位 identity 完全相同；Photoshop 的 8→16 位转换与简单 byte×257 最多差 1 个 16 位 LSB。故 16 位使用 Photoshop 实际 identity16，避免将转换误差归给滤镜。**这些 16 位输入来自 8 位转换，没有独立的非字节网格源16样本，不能证明全部 16 位精度与 Photoshop 一致。** 此限制与项目 source16 单元测试的精度保留属于不同证据。

最新结果位于 `artifacts/photoshop-native/measurements/v3/comparison.json`；下方首轮表格是 HSL 修复前的历史测量，历史摘要保存在 `measurements/history/*-before-hsl.txt`，不可把其旧数值当作当前 JSON。项目测试、Compositor C 参考和数学期望都没有被当作 Photoshop 输出。本工具不触发 Photoshop GUI，不重写原生参考，仅写测量产物和项目对照图。

## 不透明 RGB 的结果

所有误差为该位深输出 LSB。ROI 要求原输入、参考输出、项目输出的 Alpha 都完全不透明。16 位指标不能直接与 8 位数字比较；除以 257 可作归一化量级参考，但不能替代原始16位误差。

| 操作 | RGB8 MAE | RGB8 最大误差 | RGB16 MAE | RGB16 最大误差 |
| --- | ---: | ---: | ---: | ---: |
| Identity | 0 | 0 | 0 | 0 |
| Invert | 0 | 0 | 0 | 0 |
| Levels：Gamma 1.25 | 0.0029 | 1 | 1.3916 | 177 |
| Levels：输入 23/221，Gamma .85，输出 11/240 | 0.2017 | 1 | 4.5781 | 11 |
| Gaussian：半径 3 | 0.0458 | 2 | 9.4385 | 321 |
| HSL：Hue 25，Saturation 30，Lightness -10 | 1.6812 | 24 | 411.4724 | 6210 |

反相的不透明结果完全相同；色阶8位结果最多相差1，仍不能称其所有工作流完全一致。Gaussian 16 位不透明 MAE 约为 .0367 个8位量级；HSL 的最大偏差约24个8位量级，明显大于色阶和模糊。

| --- | ---: | ---: | ---: | ---: |
| Identity | 0 / 0 | 0 / 0 | 0 | 0 |
| Invert | 0 / 0 | .0139 / .9686 | 0 | 0 |
| Levels Gamma | .0020 / 1 | .9766 / 177 | 0 | 0 |
| Levels Range | .1400 / 1 | 3.3476 / 11 | 0 | 0 |
| Gaussian3 | .1286 / 2.8118 | 24.3573 / 383.9839 | 2 | 491 |

颜色滤镜都保留原 Alpha；Gaussian Alpha 平均误差为 .1574 / 42.2313，P95 为1 / 237（8/16位）。最高差异出现在透明轮廓，例如 RGB16 `(501,181)` 的参考 Alpha 5390、项目5881。这里表明透明边缘存在可测偏差，但尚不能单凭一个半径确定是核形状、半径映射、截断还是取整。

低 Alpha 的直色误差会被反预乘放大，不能当作普通不透明色偏。工具另外记录至少5% Alpha 的半透明ROI、低于5%ROI及预乘颜色；完全透明处的 straight RGB 不计入可见颜色指标，最大可见差异坐标也排除双方都透明的像素。高斯的可见直色最大值255/65535不代表合成视觉误差达到这个量级，预乘表才体现其实际贡献。

## 首轮判断（补充样本前的历史记录）

1. **Gaussian 暂不改算法。** 半径3的不透明结果接近，Alpha 轮廓有差异。需真实 Photoshop 半径1/6、中心/边缘脉冲、黑白阶跃、透明彩边及锁定透明开/关输出；测 σ_eff/FWHM、能量、质心、尾部和边缘10–90%宽度。只有多个半径及留出形状都支持同一换算时，才调整参数映射或边界。不能用这一张网格拟合系数后宣布 Photoshop 核一致。
2. **HSL 优先拆参数。** 当前只采集联合设置25/30/-10，无法区分色相公式、正饱和度公式、亮度方式与33³插值。下一批分别采 Hue-only25、Saturation-only30、Lightness-only-10，再采第二个参数值和独立色块/灰阶/色相环/照片。偏差已证明，但还不足以授权一个特定公式作为修复依据。
3. **Levels 16 位进一步查局部峰值。** Gamma MAE小但最大177，需检查对应灰阶与Alpha位置，使用独立真实16位渐变和第二组Gamma；Range最大11也可能含Photoshop内部精度/量化差异。首轮8位≤1不能代替16位逐像素验收。
4. **扩大到实际使用流程。** 滤镜预览/提交、撤销、保存重开、调整层和选区应另测。本轮未测 Curves 横向端点或 HDR 负值 Gamma，不能为已实现的 Stage2 语义修复提供真实 Photoshop 像素结论。

首轮只新增测量脚本，随后依据下述新样本修改普通 HSL；真实参考均保留原样，产品对照 PNG 文件名含内容 hash，避免相同参数的新算法输出覆盖旧输出。

## 补充真实参考及 HSL 修正

`outputs/supplement` 增加 289×17 的 17³ 不透明 RGB 色彩格（RGB8 及 Photoshop 转换的 RGB16）：独立 Hue25、Saturation30、Lightness-10、联合25/30/-10，并增加 128×128 不透明阶跃/单点组合的 Gaussian1/3/6。`outputs/refine` 增加纯 Lightness+10/+30，以及真实 Photoshop ActionManager Curves `(16,0),(239,255)`。这些是实际 Photoshop 导出，不是产品生成的期望值。补充日志中的 PSB 保存还有一个失败记录，不将整个日志标成全通过；本报告只对有 PASS 的对应 PNG 比较。

纯 Lightness 的参考表明普通模式应按 RGB 向黑或白混合：负值 `c×(1+t)`，正值 `c+(1-c)×t`。联合参数进一步证明 Lightness 必须先于 Saturation：只放在 HS 后面，联合 RGB8 色彩格仍 MAE4.13/max26；先混合 RGB，再执行 HS 后降为 MAE.357/max2。因此这次统一修正8/16位普通 HSL 的顺序，Colorize 和原版颜色范围权重规则保持不变。它有意偏离 Compositor 的 HSL-L 模型；原生历史 fixture 不改，只限定旧参考检查的有效范围。

## Gaussian 的多半径测量：保留差距

对不透明阶跃与点样本，用 `scripts/measure-photoshop-gaussian.ts` 读取真实输出和产品对照图，测中心阶跃一阶差分的有效 σ、10–90%宽度，并测下半单点的水平中心切片。完整二维下半窗口会混入上方阶跃的尾部，所以没有把窗口总亮度误称为单点能量。8位点样本尾部因取整丢失，16位切片更有参考价值。

| 半径 | 阶跃 σ PS16 / 项目16 | 单点水平 σ PS16 / 项目16 | 阶跃/点组合 RGB16 MAE / 最大 |
| --- | ---: | ---: | ---: |
| 1 | 1.08254 / 1.03747 | 1.08253 / 1.03742 | 18.0345 / 1401 |
| 3 | 2.94383 / 2.98817 | 2.93942 / 2.98808 | 17.0405 / 422 |
| 6 | 5.99997 / 5.94257 | 5.96291 / 5.93184 | 39.5700 / 570 |

有效σ的误差随半径变化方向，不能由统一倍数修好。项目Gaussian算法本次保持不变；透明网格的Alpha差距也仍存在。实际 Photoshop 的私有核、边界策略、锁定透明及自然照片效果尚需更多独立样本；报告保留测量，不冒充GPU全流程一致。

复现命令：三次 `npx tsx scripts/compare-photoshop-reference.ts artifacts/photoshop-native/outputs/{v3,supplement,refine}`（分别运行），再 `npx tsx scripts/measure-photoshop-gaussian.ts`。原始参考未修改，数值回归不替代GUI预览/提交、调整层、选区及保存重开验收。
