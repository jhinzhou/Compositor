# alpha.24 工具栏与子菜单

本批修复截图中工具栏过高、子菜单缺少图标、菜单勾选与外层图标不一致的问题。

## 交互与布局

- 侧栏宽度 44 CSS px，常规按钮 30 × 30 px，图形 18 px。窗口高度不超过 740 px 时使用 28 px 按钮和 17 px 图形。
- 高度不超过 640 px 时改为 72 px 宽双列，保留至少 28 × 28 px 点击区域。小窗口仍允许滚动作为兜底，不能通过隐藏溢出来遮住工具。
- 所有工具组使用同一条显示规则：当前工具属于本组时显示当前子工具，否则显示本组记住的子工具，没有记忆时使用第一个子工具。外层图标、菜单勾号、打开时的键盘焦点，以及点击外层按钮激活的子工具必须一致。
- 子菜单每项有独立 SVG 图形、名称、组快捷键。勾号只表示实际选项；鼠标悬停或方向键移动仅改变高亮，确认后才选择。
- 右键、长按、Shift+F10 展开；方向键 / Home / End 移动；Enter 或空格选择；Escape 关闭。
- J 组按污点修复、移除、修复、修补、内容感知移动、红眼排列。Shift+J 逐项循环。

## 代码接口

`displayedToolGroupEntry(id, state, remembered?)` 返回有效注册项，忽略已移除或跨组的记忆 ID。`toolGroupIconProps(entry)` 返回 `{ tool, variant: entry.id }`，供外层和子菜单共同调用。`EditorToolIcon.vue` 使用 `editor-tool-icons.ts` 中的矢量定义。

组件与分组专项测试已运行：13 / 13 通过。测试覆盖默认/记忆/当前选项、独立图形、实际 Vue 模板及事件处理、勾号与高亮分离、键盘循环和取消清理。

`scripts/smoke-alpha24-toolbar.ts` 已提供实际 Electron 验收脚本，交由统一验收串行运行。本文件不提前宣称 GUI 通过。它检查 1440×840、1280×800、1050×700、1280×600 的实际内容区域，测量每个按钮及前/背景色块是否完整显示且无侧栏滚动；逐项操作全部 21 个子工具，核对外层图标、非活动组记忆、菜单勾号、键盘初始焦点和悬停状态；验证六项 Shift+J 顺序，并检查操作没有改动图片或工程历史。仅用隔离配置与打开文件对话框路径替代边界，截图来自实际 Electron 窗口。

图片编辑算法与 Photoshop 的效果差异由各自验收覆盖，图标或菜单存在不构成算法一致的证据。

## 新修复工具的画布接入

App 已接入独立 Remove 笔划、Content-Aware Move 选区拖动与 Red Eye 点选/矩形框选。内容感知移动在鼠标松开后保留私有预览和该次交互锁，Enter / Apply 才提交一次历史；Escape、窗口失焦、切换工具、撤销、工程操作或目标图层/工程版本变化会取消草稿并释放锁。其参数变化重绘同一草稿，供体随机种子和捕获的工程版本保持不变。图层内容在确认前不修改。

移除支持笔径、硬度、不透明度、闭合圈选填充、透明度保护和方括号调笔径。红眼以默认 64 文档像素范围点选，拖动则使用规范化矩形；瞳孔大小和变暗量以 0–100% 显示，默认 50%。新工具仅针对当前栅格图像，后端保留 RGB8、2 MP 和运算预算检查，不能将其描述为 Photoshop 全能力或全尺寸效果一致。

新增 `retouch-tool-ui-alpha24.test.ts` 的 7 项检查通过：点选/反向框选坐标、各算法及参数区分、固定种子、过量笔划拒绝、真实 App 取消/失败释放、并发确认和等待鼠标结束后的重复确认防护。全项目 `vue-tsc --noEmit` 通过；实际窗口验收仍由统一串行运行完成。
