# alpha.28 采样候选模型冻结

本文件冻结一个有限适用的放大重建候选，供根代理在此后采集新的独立原生样本。没有将旧留出再次作为新独立验证，也不把此项放大改善描述为强透视缩小已解决。候选来自新的有效 Photoshop 27.11.0 DOM Image Size 核控制和固定尺寸透视控制；原生源、参数、历史和 SHA 已由根代理验证。未访问 opaque-holdout / alpha-holdout 的新原生输出。

## 冻结算法

- 像素坐标仍为源像素边缘，采样中心 `u-.5, v-.5`，没有固定相位偏移或几何补丁。
- 仅 High quality、非对齐直接复制、非蒙版，且逆变换局部 Jacobian 的最大奇异值严格小于 `1−1e-9` 时使用候选。即两个主轴均为真实放大；等比仿射缩小仍用已验 Lanczos3，其他缩小保持旧 Mitchell。
- 新重建为标准 Catmull–Rom (`B=0,C=.5`) 的 `9/8` 源空间尺度扩展，完整权重归一化。原 support 2 因此扩大为 2.25 源像素。`9/8` 来自本轮可观测的低幅脉冲/阶跃有效核控制，不针对图片名、几何样本或旧留出调值。
- 新核仅在其真实支撑范围内全部为原格式不透明 alpha 的区域使用。RGB8 不透明为 255，RGBA16 为 65535，Float32 HDR 为 1；不以近似 alpha 阈值宣称不透明，不改源数组或转成 8 位。
- 用源中心周围 8×8 alpha 邻域计算最近非不透明/源外围样本的 Chebyshev 距离 `d`。新核权重为 `clamp((d−2.25)/(3−2.25),0,1)`。`d≤2.25` 保留原 Mitchell；`d≥3` 全用新核；中间宽度 .75 连续过渡。2.25 是新核支撑边界，3 是 `ceil(2.25)`，宽度来自这两个支撑量，不从留出拟合。
- 源范围外视为非不透明；蒙版仍使用原背景值/外围语义。透明或半透明实际支撑内保留旧核，非零过渡只发生在两个核都不会接触非不透明源样本的区域，所以 output alpha 必须逐像素与旧路径相同。不是用整体 alpha MAE 掩盖局部改变。
- 高位深值保持预乘数值，最终调用者各量化一次。HDR RGB 不夹到 alpha/白位，不丢弃负值或超白值。默认公共 sampler 仍是 Mitchell，新核由 Crop 调用者显式选择。
- 新核最坏工作按 80 taps/输出像素计入：8×8 guard 和宽核累积复用同一批源位置，共64；需要连续过渡或 fallback 时最多另16个旧核 taps。不得把64次 alpha 探测从120M预算漏掉，不新增全图 alpha 距离场或隐藏内存分配，512 MiB gate 保留。

## 校准与旧全样本回归

研究脚本 `scripts/research-crop-kernels-alpha28.ts` 与源生成器 `scripts/create-crop-kernel-alpha28-inputs.ts` 均不修改生产。比较基线来自实际 `perspectiveCropRaster`，不是另写近似基线。旧 alpha24/25 的图形兼容角点转换仅在研究 fixture 装载时按已有测试契约使用，不进入新算法。

25 个旧样本跨 alpha24/25 自然图、alpha26 精确角点/灰阶映射、alpha27 仿射缩小、真透视缩小、透明放大、真实鼠标输出。新 `wide-catmull-9/8-smooth-opaque` 候选逐例 RGB MAE/max 没有恶化，**每例 alphaRegressionPixels=0**。相关完整报告：`artifacts/alpha28-sampling-research/old-cohorts-smooth/comparison.json`。

未做 guard 的宽9/8核虽然改善放大 RGB，却使源边界 alpha 和整体 alpha MAE 回退，已拒绝全域使用。硬6×6 opaque guard 的整数源单元切换存在连续性风险，已改成上述距离带连续过渡；不能将硬 guard 当成最终冻结模型。

## 独立验证仍待完成
