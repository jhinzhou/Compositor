# Photoshop PSD / PSB 能力矩阵

适用版本：`0.3.0-alpha.10`，核验日期：2026-10-10。

本文件描述 PSD/PSB 的导入、编辑结构和导出边界。当前不是完整 Photoshop 文件兼容实现，也没有 Photoshop 桌面版同图渲染验收。文件能打开、合成预览相似、编辑结构可以往返是不同的验收条件。

## 能力矩阵

| 内容 | 导入与项目内编辑 | PSD / PSB 导出 | 已知限制 |
| --- | --- | --- | --- |
| RGB 8bit 像素层 | 保留未预乘 RGBA、坐标、透明度、可见状态 | 可编辑普通像素层 | 当前工作空间固定 sRGB；不具备完整 ICC 色彩管理 |
| RGB 16bit | 显式警告后量化为 RGBA8 | 输出 RGB 8bit | 不是 16bit 编辑或精度无损往返 |
| CMYK、其他颜色模式、32bit HDR | 明确拒绝 | 不支持 | 不做无提示的颜色模式转换 |
| PSD / PSB | 实际读取版本 1 / 2 | 实际写出 PSD / PSB | 仍受本项目 512 MiB 文件、30,000 边长及像素/内存预算限制；PSB 不意味着可处理任意大文件 |
| 文件夹、顺序、透明度、隐藏状态 | 保留层级及底到顶顺序 | 保留层级及排序 | 编辑器以 pass-through 显示组；隔离 Normal 组及其他原组混合方式会报告预览限制，并保留源模式作往返 |
| 24 种原生混合模式 | 可映射为原生模式 | 可写为 Photoshop 模式 | 不在集合内的普通图层模式降为 Normal 并报告；没有完整高级混合/Blend If |
| 图层蒙版、组蒙版 | 保留灰度像素、补丁坐标、外围默认值、启用及链接状态 | 写为 Photoshop 光栅蒙版 | 第二份 real/vector-combined mask 不能独立导入 |
| 蒙版密度、羽化属性 | 导入为可编辑非破坏属性；密度向白色混合，羽化按源蒙版像素计算；预览及 PNG 导出保留源蒙版 PNG | 等比例缩放转换羽化单位并写密度/羽化参数；非等比例缩放时烘焙有效蒙版并提示，项目源蒙版仍可编辑 | 羽化范围 0–250 源像素，受 512 MiB 工作内存预算限制；原 PSD 超范围羽化预览受限，未编辑时保留源值；独立矢量蒙版参数仍仅保留元数据，不保证 Photoshop 算法逐像素一致 |
| 剪贴关系 | 支持同组连续兄弟层的像素基底 | 保留对应 clipping 标记 | 非连续关系明确拒绝导出；部分组/特殊基底关系不支持 |
| 横排文字 | 转成可编辑基础文字，并保留导入像素回退 | 写真实 TySh 文字层，支持 UTF-16 字体/颜色分段、点/框文字、段落对齐、字距/行距与仿射变换 | 字体可用性、基线、字体度量、段落重排仍可能不同；竖排及路径文字只能像素回退 |
| 原文字的高级排版/warp | 未编辑的源描述符可以保留，单纯平移同步矩阵 | 原像素、文字参数与几何保持时保留源描述符 | 重新生成或显式编辑文字后，以项目支持的基础排版为准，不恢复旧 warp/高级样式 |
| 矩形、圆角矩形、椭圆 | 基础形状可编辑，保留源像素；特定缺失像素的基础形状可重建 | 写真实 SoCo / vmsk / vogk 结构，支持旋转/翻转 | 不保证 Photoshop 与项目的抗锯齿像素一致；直线当前仍为光栅回退 |
| 任意源矢量/描边 | 不提供完整编辑器；保留描述符及像素回退 | 未编辑时可保留原路径、填充、描边描述符 | 用户重画、改动像素或几何后不复活旧矢量。没有完整钢笔、任意路径及矢量蒙版编辑 |
| 六类图层样式 | 描边、投影、颜色叠加、内阴影、外/内发光转为可编辑样式 | 写真实 Photoshop 效果描述符 | 编辑器只有单实例与基础参数；混合、轮廓、扩展、中心描边/发光等可能近似，完整渲染未对齐 |
| 原复杂/多实例样式 | 描述符保留，非支持部分明确报告 | 用户未编辑样式时可保留 | 用户编辑、复制或清空原生样式后采用新状态；改回同一参数也不会重新启用旧斜面/多实例等描述符 |
| 八类调整层 | Levels、Curves、HSL、Exposure、Invert、Color Balance、Black & White、两端点不透明 Gradient Map 可编辑 | 写为独立 Photoshop 调整层 | Photoshop 内核可能不同；Gradient Map 仅支持当前项目的简单两端点模型；HSL invertRange 不独立导出 |
| 其他 Photoshop 调整层 | 跳过并明确报告 | 不支持独立导出 | 不能声称复杂 PSD 所有调整效果保持；其他项目原生调整可能只体现在合成预览 |
| 完整锁定、位置锁定 | 映射到项目的锁定能力 | 写为 Photoshop protection flags | 单独像素/透明像素、画板保护保留源描述符但项目不分别实现；用户显式修改锁定后采用新状态 |
| 智能对象、智能滤镜 | 有像素回退时作为像素层导入并报告 | 不恢复完整源对象/滤镜结构 | 不导入嵌入/链接源文件，没有完整智能对象替换和智能滤镜编辑 |
| DPI、参考线、全局光 | 保留已支持资源 | 写出已支持资源 | 不代表所有 Photoshop 文档资源均兼容 |
| 合成预览 | 图层导入使用像素回退与支持的结构 | 可写入实际编辑器合成 PNG | 完整预览能显示不代表其他应用按图层重算必然相同 |
| 已变换像素层 | 支持本项目变换 | 重采样成轴对齐图层像素 | 图层自身的可编辑原始变换不作为智能对象保留；文字/基础形状另写可编辑描述符 |

## 源元数据与用户编辑

源描述符仅用于保留尚未编辑的 Photoshop 内容。用户的操作具有优先级：修改后再改回同一数值、复制相同效果、删除再添加同一白蒙版、完整锁定后解锁，都不能触发旧复杂描述符重新生效。撤销可以通过正常历史快照恢复原始描述符。

蒙版密度和羽化已成为项目原生属性，修改蒙版像素后仍然保留并重新应用；删除再建立或替换蒙版时按新的蒙版状态处理。过时的源描述符失效不等于丢弃用户可编辑的原生属性。

此规则由 `src/core/photoshop-metadata.ts` 与真实编辑动作共同执行。导出文字额外检查原始像素 hash；像素绘制、重新生成文字/形状、蒙版更新、样式复制/清空、锁定修改均使相关源描述符失效。

## 验证证据

最初 PSD 专项验证为 **43 项通过**；独立审查新增文字重绘和八项源元数据失效/撤销回归后，PSD 格式专项为 **52 项通过**。格式专项不包含 Photoshop 操作习惯测试，使用以下固定文件范围核验：

```sh
npx tsx --test tests/photoshop-adjustments.test.ts tests/photoshop-complex-render.test.ts tests/photoshop-controller.test.ts tests/photoshop-editable.test.ts tests/photoshop-io.test.ts tests/photoshop-metadata.test.ts tests/photoshop-production.test.ts tests/photoshop-vector.test.ts
```

证据覆盖：

- 独立手写 Adobe PSD 像素与 16bit 字节结构，避免完全依赖同一库自行生成并自行验证。
- 实际 PSD/PSB 文件字节、worker、production Node ESM、真实 TySh/SoCo/vmsk/vogk/效果与调整层结构。
- hue2 的 100 字节 Master、Colorize 与六个色段布局及带符号角度。
- 嵌套组蒙版、图层蒙版、剪贴关系、样式、文字、调整层、DPI 与锁定组成的组合文件。
- 真实 CanvasKit/Skia 合成：合成预览逐字节写回；导出再导入重绘，组合测试的最大 RGBA 差异 ≤ 1。
- 样式修改再改回、清空仅有斜面源样式、复制效果/蒙版、删除再建立相同蒙版、锁定再解锁、重新生成文字、相同像素绘制后的描述符失效；撤销恢复原始结构。

alpha.9 另有 `tests/mask-properties.test.ts` 的 10 项非破坏蒙版属性验证，覆盖源 PNG 不变、Undo/Redo、保存重开、有效蒙版选区以及 PSD 等比例单位转换和非等比例烘焙；上述固定文件范围的蒙版密度/羽化回归也已更新为像素编辑后保留原生属性和导出参数。

这些是本项目的文件结构与往返稳定性验证。尚未完成 Photoshop 桌面版实测、真实复杂 PSD 语料库覆盖、跨应用排版/样式重算一致性和完整颜色管理验收。

## C2导入补丁：alpha.10

新增Raw/RLE通道边界校验与固定库的输入适配，不改变上表可编辑结构范围：

- RGB8/16图层及mask使用自身尺寸检查Raw字节数、RLE行表、PackBits包边界及展开长度，PSB使用4字节行表。确证坏包以INVALID_IMAGE拒绝；ZIP仍由原库处理，不宣称新增完整压缩格式校验。
- 合法RGB16 RLE预先解压为大端Raw字节，避免固定ag-psd31.0.3的RLE路径忽略bitDepth。Raw16/RLE16及NOP在PSD/PSB中导入的量化后像素一致；仍然输出RGBA8。
- 合法odd8 Raw行padding剥除后走原Raw路径；RLE行pad/NOP保留，实际多行像素与无pad输入一致。原input及parsed descriptor不被修改，节点内解压/解码/量化暂存有512MiB预算。
- 已加入4份合法自产、独立Apple ImageIO生成的PSD；该工具版本产生的层RLE坏包现被正确拒绝，未将它们计为有效复杂PSD语料。真实Photoshop作者文件/视觉验收仍未完成。

C2新增19项测试，格式专项合计71项通过。该计数包括来源与异常输入分类，不代表71种Photoshop功能完全一致。详细来源、初次红灯、修复和24项语料目标见 [C2语料报告](PHOTOSHOP_CORPUS_C2_2026-10-10.md)。
