# alpha.26 透视裁剪采样研究

截至 2026-10-13，本批已经实施像素覆盖范围驱动的下采样抗锯齿，以及非缩小采样路径的性能优化。独立原生参考证明缩小时的高频残差改善，仍不能把高频图案、透明边界与 Photoshop 的效果差异标为全部关闭。自动尺寸由单独的专项研究负责，此文只讨论给定原生输出尺寸后的采样。

## 原生基线与诊断方式

Photoshop 27.11.0 的本机偏好实际读取为 `ResampleMethod.BICUBICAUTOMATIC`。新输入 PNG 没有 ICC，原生 `colorProfileName` 查询失败，不能推定所有颜色管理设置相同。现有生产路径在 RGBA8 编码颜色域内插值，以预乘 alpha 累加；RGB16/HDR 则直接使用原有预乘高精度数据。

复用不可变 alpha.24/25 原生案例，并新建两张独立、自行绘制的 384×256 输入，包含线性颜色渐变、脉冲、4/3/1 像素棋盘格、硬边和半透明边界。生成入口是 `scripts/create-perspective-sampling-alpha26-inputs.ts`。新输入不含用户原图。

`scripts/measure-perspective-sampling-alpha26.ts` 逐项比较 Mitchell、Catmull–Rom、Keys、B-spline、双线性、相位量化、权重量化、线性 sRGB 域及采样中心变化。输出全图 RGB MAE/RMSE/max/P99、alpha MAE/max、低频/高频/源边界分区和最大残差位置。每种候选均输出实际 PNG，不使用候选分数改写测试门槛。

RGBA8 的四点公共 API 保持文档边缘坐标。原生 GUI 采样中心的转换只用于既有 Photoshop 对照辅助函数，没有修改命令语义，也没有根据样本名选择参数。

## 既有七个原生案例的结论

这七例的采样点都在源图内部，边界分区数量为零。因此原先较低的全图 MAE 不能证明画外或透明边界效果已对齐。

残差集中在红眼测试图的高频纹理/高光附近。高频分区 MAE 约 3.49–7.12，低频约 0.19–0.37。更锐的 Catmull–Rom 在少数案例中略降平均误差，但把最大误差从 19 增到 25、从 31 增到 39、从 33 增到 40，alpha.24 的倾斜例也由 41 增到 50。线性 sRGB 采样普遍增加误差，相位/权重量化及固定四分之一像素偏移未呈现统一收益。这些候选没有进入生产路径。

## 新采集暴露的差异

以下输出保留在独立压缩 fixture 中，其 `status=DIAGNOSTIC_NOT_PARITY_ACCEPTED`、`geometryVerified=false`，没有设置通过阈值。

| 案例 | 原生实际输出 | 观察到的源四角 | 修复前旧辅助 profile 的 RGB MAE / max | 修复前 alpha MAE / max |
|---|---|---|---|---|
| calibration | 300×200 | (20,15), (350,40), (320,238), (25,220) | 12.765 / 254 | 0 / 0 |
| holdout | 268×210 | (55,0), (383,25), (355,225), (0,255) | 18.679 / 255 | 0.361 / 101 |

Holdout 最初请求的四角是 (55,10), (370,25), (355,225), (5,245)，原生画布吸附改变了实际位置。诊断使用观察到的最终位置，没有把吸附引起的坐标差异算作已验证的核差异，也没有更改用户的吸附偏好。

从 calibration 的线性 R/G 渐变反解映射，估计有效角点约为 (20.358,16.371), (351.085,41.336), (320.970,239.380), (25.426,221.143)。它们与观察四角加 0.5 像素的公共转换存在约 0.8 像素纵向差异，且不等同于统一固定偏移。单像素棋盘对这种相位差很敏感；暂时不能区分原生内部坐标、指定输出尺寸的两阶段重采样与核差异。

把 B-spline 与中心分数映射组合，诊断 MAE 可降至 calibration 7.969、holdout 12.805，但 holdout alpha max 仍为 72；仅把图像模糊以降低均值不满足效果验收，因此未采用。待精确 crop-event payload、独立轴对齐缩放和上采样参考后，再决定是否需要尺度相关预过滤或独立插值模式。

### 后续收到的确切 600×400 原生事件

原生 `perspectiveCrop` 通知保留的角点是 (20,0), (351,40), (321,239), (25,221)，目标为 600×400；和屏幕观察角点存在右/下边 +1 及吸附差异。这个新事件与输出单独固化在 `photoshop-27.11-perspective-sampling-alpha26-upscale-diagnostic.json`，该事件标注 `geometryVerified=true`，没有改写前两次失败记录；后续确切事件和ActionManager参考分别独立标注。

新描述符不能未经验证就送入旧 alpha.24/25 的 inclusive-center 辅助 profile。沿用旧 profile 的 MAE 为 13.133、max 220；直接把 native descriptor 作为边缘角点、采样输出像素中心，Mitchell MAE 为 5.900、max 107，alpha max 40。直接边缘映射的低频 MAE 为 0.180，高频为 25.659；37 个源边界像素仍有 alpha 差异。Catmull–Rom 高频 MAE 增到 33.115，B-spline 为 33.198，均没有支持替换生产核。

公共 API 维持边缘四角语义；这次新原生描述符与旧样本使用的 UI 像素约定不同，不是改变显式 API 语义的理由。下一步需同角点的精确缩小输出和原生实际叠层/背景状态，继续区分亚像素映射、背景填充与 Automatic 插值。补充的 `perspective-sampling-ramp-mapping.png` 全图都是已知 X/Y 渐变，用于全局反解映射，不能把拟合参数直接写进产品。

另一次使用原有自然频率输入，原生事件为 (60,40), (431,55), (401,281), (75,261)，实际输出 387×257。新 case 单独保存在 `photoshop-27.11-perspective-sampling-alpha26-oldquad-diagnostic.json`，不改旧 alpha.25 fixture。直接边缘映射的 Mitchell MAE 为 0.349618、max 30、alpha 完全一致；错误沿用旧 inclusive-center helper 时 MAE 为 0.966934、max 167。Catmull–Rom MAE 虽略低为 0.347889，max 却增到 40。这个独立事件进一步支持新的 native descriptor 按边缘坐标处理，未给出替换采样核的证据。

## 已实施且可验收的改进

### 由像素覆盖范围驱动的抗锯齿

`src/core/crop-actions.ts` 合成逆透视与图层 placement 的 source homography，由每个输出像素的 Jacobian 推导源 X/Y 足迹；仿射情况提前缓存不变足迹。High quality 且非对齐样本在缩小时扩展 Mitchell 支撑并归一化完整核，而非仅归一化画内部分，以保持透明和画外蒙版语义。足迹不超过一个源像素时走原路径，精确对齐继续保留原始像素值。RGBA8/RGB16/HDR 共用足迹，但保持各自原有颜色数据和最终格式量化。

本次 crop 跨图层共用实际 tap 计数，扩大支撑不能突破原有 1.2 亿采样工作预算；超过时以 `RESOURCE_LIMIT` 拒绝。没有按图片名选择核、固定相位偏移或把源边界一律改成 clamp。

下面均为 fresh-source 的 Photoshop ActionManager 独立参考，以确切 descriptor 边缘四角直接执行公共 API；目标尺寸由请求显式提供。其 600×400 RGBA SHA 与另一次真实 GUI crop 输出完全一致。采样 fixture 保留 native-actionmanager 标签，不冒充 GUI 操作，也不是自动尺寸证据。

| 独立参考 | 修复前 MAE / max / alpha max | 修复后 MAE / max / alpha max |
|---|---|---|
| exact quad 300×200 | 6.536533 / 120 / 42 | 5.707133 / 103 / 28 |
| exact quad 600×400 | 5.900449 / 107 / 40 | 5.900449 / 107 / 40 |
| requested quad 300×200 | 7.600256 / 137 / 0 | 6.680822 / 118 / 0 |
| full-source axis 300×200 | 7.686817 / 111 / 28 | 3.143678 / 47 / 14 |

自然频率 GUI event 留出仍为 MAE 0.349618 / max 30 / alpha exact。旧 alpha.24/25 原生参考全部通过既有门槛，未修改其 fixture；部分旧平滑案例的舍入使 MAE 发生小变化（例如 strong-trapezoid 0.307146→0.309701），应与高频缩图改善分别看待，不能声称所有案例每个统计量都严格下降。

alpha.21 另一个原生固定尺寸参考有精确 `different channels` 快照：194393→194442，增加 49 个通道（总 RGB 通道的约 0.021%）。它的绝对误差反而降低：MAE 4.48646977→4.47901740，RMSE 14.53794327→14.38924259，max 237、P99 77、alpha 0 不变。原始 fixture 保留，测试准确固定新通道数，同时保留原 MAE<5/RMSE<15 预算并新增不得超过旧实测 MAE/RMSE/max/P99 的更严格断言，没有以扩大门槛解决快照变化。

新增足迹测试包含四个原生目标案例、RGB16/HDR 的真实小数 alpha/负值/超白值与源缓冲不变、旋转足迹、近单位浮点计数，以及大支撑和跨图层共用预算守卫。最终 78 项定向测试通过，最终 typecheck 通过。

### 非缩小路径的性能

`src/core/crop-sampling.ts` 将格式判断移到 tap/channel 循环外。直通 RGBA8 的两轴权重由 32 次求值改为 8 次、复用 16 tap；预乘 RGB16/HDR 保持原核求值路径，避免权重临时数组导致混合格式调用减速。每个 tap 的权重乘法顺序与累加顺序保留，最后的格式量化仍由既有调用方完成。

`tests/crop-sampling-alpha26.test.ts` 验证默认非缩小核在 8/16/HDR 的亚像素相位和画内外值逐浮点值一致、透明隐藏 RGB 不污染结果、HDR 负值/超白值和小数 alpha 不被降到 8 位，以及画外蒙版默认值。这里的逐位保持限于不需要扩大足迹的采样；缩图变化由上述独立原生参考与精度测试验收。

`scripts/benchmark-crop-sampling-alpha26.ts` 在每种格式上执行 40 万次不需要扩大足迹的采样、交替 7 轮，并检查 checksum 完全一致。最终版本本机中位加速约 RGBA8 1.60×、RGB16 1.52×、HDR 1.40×。这是采样函数局部基准，不代表扩大核的缩图路径、整体透视裁剪、渲染或 Photoshop 速度。

### 两阶段重采样假设的原生反证

`scripts/compare-native-perspective-stages-alpha26.ts` 比较原生显式目标透视裁剪与原生自动透视裁剪后再执行 Automatic Image Size。相同角点先得到 333×221 再变到 300×200，与直接目标的 RGB MAE 为 5.052228 / max 115；变到 600×400 为 8.705894 / max 152；requested quad 为 5.282411 / max 106。只有轴对齐全图案例两者 RGBA SHA 完全一致。因此一般透视不能简单用“先自动尺寸 warp 再 resize”还原，本次未采用该路径。

## 下一步的独立验收

1. 现已完成确切事件、同四角300×200/600×400、轴向全图缩小及自动后Image Size参考。继续采集其他源频率和半透明边界的独立留出；仅凭屏幕观察的旧失败记录保持 `geometryVerified=false`。
2. 在固定几何上进一步区分脉冲、不同频率棋盘、旋转方向性足迹与Automatic放大的残差。当前确切四角缩小的高频分区MAE为24.120607，放大为25.659076；低频放大MAE0.180331不能代表高频等价。所有核候选须同时保留既有自然频率案例精度，不能用模糊替代正确映射。
3. 单独验证画外和半透明alpha。确切四角缩小/放大边界alpha max仍为28/40，轴向缩小alpha MAE0.116933/max14；现有完整核归一化保留透明语义，但尚未复刻原生边缘覆盖。
4. RGB16/HDR 继续保持公共显式尺寸、源精度与 alpha 语义，并单独获取原生高位深参考；RGBA8 验收不能代替高位深效果结论。扩大源支撑会增加实际工作，大幅缩小或多图层可能触发原1.2亿tap预算，不能把不扩展足迹的局部基准速度推广到该路径。
