# 中文 / English 国际化实现与验收

版本：**0.3.0-alpha.7**。本轮在 alpha.6 原版功能对齐基础上加入应用国际化；Photoshop 能力增强和 Windows 原生验收仍按原定安排延后。

## 使用方式

标题栏使用紧凑的 **ZH / EN** 按钮。点击一次切换中英文；当前语言加粗并提高亮度，另一语言保持灰色常规字重。支持键盘 Tab 聚焦以及 Enter / Space 操作。保存期间阻止重复切换，并保持键盘焦点，避免设置竞争和焦点丢失。

原生菜单也提供 **帮助 → 语言 → 简体中文 / English**。首次启动按系统首选语言选择：中文环境使用简体中文，其他语言环境使用英文。主动选择的语言保存到 Electron userData 下的 `language-settings.json`，下一次启动优先读取该设置。

设置与工程数据分开保存，使用临时文件加原子重命名；写入失败时保留原语言并显示错误。设置损坏、版本不支持或不可读取时回退到系统语言。隔离自动化测试默认英文，但仍会读取并验证自己的语言设置文件。

- 画布尺寸、图像大小、裁剪、选区变换、色彩范围、主体 / 对象选区、背景移除、内容识别填充、颜色、渐变、蒙版、图层效果。
- 24 种混合模式、滤镜参数、Camera Raw 预览及示波器、文字 / 形状 / 字体面板。
- RAW 导入、PSD / PSB 转换报告、导出选项、恢复和近期工程面板。
- 内置 Agent 的设置、按钮、状态、校验反馈，以及 MCP 连接界面和内置编辑活动名称。
- macOS / Windows 共用的原生菜单模板、打开 / 导入 / 保存 / 导出及未保存提示；Windows 实机显示仍待后续验证。

5 份词典共 **1,747 个去重消息**，包含内置诊断和动态参数消息。30 个 Vue 组件经过源代码审计，检查模板文本、可访问性标签、词典占位符及共享术语一致性。英文作为规范消息和回退文本，中文作为对应词典；没有引入额外运行时依赖。

工程名、文件名、用户图层名、实际文本内容、字体家族名、模型名、API URL、服务响应和 MCP JSON 保留原值。已有默认文档标题也保持工程原值。PNG / JPEG / PDF 等格式名、RGB 等技术名称与字体预览字形样本保留原文。

## 实现约束

`src/shared/i18n.ts` 提供语言类型、词典、占位符插值和已知诊断的显示翻译。`src/renderer/i18n.ts` 提供 Vue 响应式语言状态；打开的面板无需重新挂载即可更新文案，保留输入草稿。

语言是应用级设置，不属于 `.comp` 工程或编辑事务。IPC 的动作类型、枚举值、工具 ID、菜单动作 ID、快捷键、原始错误代码和 MCP 返回数据均保持规范值。下拉选项只翻译显示文字，实际 `value` 保持兼容。

主进程保存语言后重建菜单，并使用现有事件通知渲染进程。重建时继续保留用户快捷键覆盖。语言接口仅开放给本地编辑器，不加入 MCP 工具集合。

内置诊断在显示边界翻译，保留错误代码、文件路径和动态变量；未知厂家 / 系统返回信息保持原文，不做不可靠的整段替换。新增语言需更新 `SUPPORTED_LOCALES`、语言名称、词典和菜单 / 按钮交互。

Electron-Vite 的 ESM shim 正则会将词典中的 “Continue import” 误认为 import 语句。本轮在 chunk 开头插入其相同 shim，让内置插件跳过字符串内部插入；未修改 node_modules。生产构建与实际运行均纳入验证。

## 验收与复现

```sh
npm run check:i18n
npm run typecheck
npm test
npm run build
npx tsx scripts/smoke-i18n.ts
npx tsx scripts/check-native-parity.ts artifacts/i18n/native-parity
```

包含新增的词典 / 占位符、语言规范化、诊断、面板渲染、设置原子写入 / 损坏回退等测试，当前共 **491 项**。桌面测试使用临时 profile 和工程，鼠标 / 键盘测试串行执行。

国际化桌面验收检查单击切换和高亮、原生菜单及快捷键、切换前后完整工程状态与 PNG 字节一致、中英文命令搜索、打开的图像大小 / Agent 面板保留草稿、实际尺寸修改与撤销、Camera Raw 预览、原生对话框参数、语言持久化和重启后的原生菜单切换。

本轮证据保存在 `artifacts/i18n/`（按 `.gitignore` 排除）。`source-audit.json` 为源代码检查，`desktop.json` 为国际化实际窗口记录，`native-parity/acceptance.json` 为 10 组常用功能串行回归，打包完整性与实际包运行单独记录。历史 alpha.6 的原版差异结论见 [原版统一验收](NATIVE_PARITY_ALPHA6_ACCEPTANCE.md)。
